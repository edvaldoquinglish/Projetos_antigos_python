Uma **lista de meus primeiros projetos 100% em python**, diversos apps com interface gráfica e python puro**usando libs como kivy, tkinter, math, random, entre outras** para gerar interface gráfica e lógica pura.

Estes projeto é totalmente **estático**, ideal para iniciantes no **python**, e permite download de meus códigos calculadora, analisadores a frequência de números históricos.
